# 수동 테스트 방법·기대 반응 — v3.18.0 (macos)

> 대상: Pure Solitaire v3.18.0 (12개 변형) — **Scorpion 변형**
> 실행: `bash scripts/package_release.sh 3.18.0` → `~/Applications/Pure Solitaire.app`
> 본 가이드는 v3.18 Scorpion 기능 검증용.

---

## 1. Scorpion 진입

1. 게임 번호 시트(`⌘G`) → **게임 형식**에서 **Scorpion** 선택 → "게임 시작".
2. 보드 레이아웃: **7열(각 7장)** + 상단 **예비 더미 3장**(뒷면) + **완성 n/4** 표시.
3. 앞 4열(0~3)은 밑 3장이 뒤집힘 + 위 4장 앞면, 뒤 3열(4~6)은 전부 앞면.

> 기대: 레이아웃/뒤집힌 카드 배치가 규칙과 일치.

## 2. 그룹 이동 (Yukon식)

1. 앞면 카드를 잡고 **그 앞면 카드와 그 위 전부를 그룹으로** 다른 열에 드래그.
2. 같은 수트 + 정확히 1단계 낮은 카드 위로만 놓을 수 있음(교대색 아님).
3. 뒤집힌 카드가 노출되면 **자동으로 앞면**으로 뒤집힘.

> 기대: 그룹 이동이 허용 규칙(같은 수트 +1랭크)에 맞는 곳만 드롭 허용, 노출 시 자동 앞면.

## 3. 예비 더미

1. 상단 예비 더미(뒷면 3장) 클릭 → **1회만** 열 0·1·2 맨 아래에 앞면 카드 1장씩 딜.
2. 예비 더미가 비면 클릭해도 동작 없음(추가 딜 불가).

> 기대: 1회성 딜, 이후 비어 있음.

## 4. 빈 열 규칙

1. 열을 비우면 그 열에 놓을 수 있는 카드는 **K만**.
2. 빈 열에 K를 놓은 뒤 다시 그 위로 같은 수트+1랭크 그룹 이동 가능.

> 기대: 빈 열엔 K만, 이후 정상 시퀀스로 쌓기 가능.

## 5. 승리 판정

1. 열 4개가 각각 **같은 수트 K→A 완성 시퀀스**(13장)가 되면 승리 배너.
2. 승리 직전에도 **자동 완성(홈셀 방식)은 동작하지 않음**(홈셀 구조 없음), 자동 플레이도 없음.
3. 승리 후 이동 수/시간 통계가 정상 기록.

> 기대: 완성 4열에서 승리, 자동 완성/자동 플레이 비활성.

## 6. 힌트/undo/redo

1. `⌘H` 힌트 → 유효한 그룹 이동/예비 딜 후보가 표시되는지 확인.
2. 이동 후 `⌘Z`/`⇧⌘Z` → 예비 딜(`dealReserve`) 포함 정상 실행 취소/다시 실행.

> 기대: 힌트가 유효 후보만 표시, 예비 딜도 undo 스택 포함.
