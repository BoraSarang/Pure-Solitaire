# 수동 테스트 방법·기대 반응 — v3.12.0 (macos)

> 대상: Pure FreeCell v3.12.0 (11개 변형) — **통계 선택 요약 / 힌트 드래그 애니메이션 / 자동 플레이 상태 표시**
> 실행: `./scripts/build_and_run.sh release` → `~/Applications/Pure FreeCell.app`
> 본 가이드는 v3.12 3건 기능 검증용.

---

## 1. 통계 선택 요약 (`⌘T`)

1. `⌘T`(또는 사이드바 통계 클릭)로 통계 시트 열기.
2. **상단 "요약 대상"** 토글에 **전체 / 선택** 2개 세그먼트가 표시됨.
3. 기본은 **"선택"** — 시트를 열면 현재 게임(예: Yukon)의 통계가 상단 카드에 표시:
   - 제목 = 현재 게임명(Yukon), 총 게임/승리/승률/현재 연승/최고 연승 + 승리 기록 있으면 **최단 승리**.
4. **"전체"** 클릭 → 상단 카드가 전체 합계(총 게임/승률/연승)로 전환.
5. "선택"으로 복귀 → 다시 현재 게임 요약.
6. 하단 **게임별 행 탭** → 상단 요약이 해당 게임으로 즉시 갱신(선택 모드). 해당 행 다시 탭 → 선택 해제, 상단이 **전체 합계**로 폴백.

> 기대: 상단 요약이 항상 "선택(현재/탭한 게임)" 또는 "전체" 중 택한 대상 통계와 일치.

## 2. 힌트 드래그 애니메이션 (`⌘H`)

1. 이동 가능한 상황에서 `⌘H`(또는 힌트 클릭) → 파란 테두리 하이라이트 대신 **카드가 소스→목적지→소스 왕복 2회** 드래그 모션.
2. 애니메이션 동안/이후 **보드 상태 불변**(이동 수·게임번호 바뀌지 않음, 실제 이동 없음).
3. 애니메이션 종료 후에도 이동 가능한 **하이라이트는 유지**.
4. `Enter` → 하이라이트된 힌트를 **실제 적용** (이전 동작 유지).
5. 스톡/플립류 이동(홈축)이 힌트로 나오면 왕복 애니메이션 대신 **하이라이트만** 표시(드래그 부적합).

> 기대: 0.45초 easeInOut 원 그대로 소스→목적지 왕복 2회, 보드 상태 변화 없음.

## 3. 자동 플레이 상태 표시 + 토글

1. 사이드바 **자동 플레이** 버튼:
   - **OFF(기본)**: 버튼이 회색/흐림, 접근성 값 "꺼짐".
   - 클릭 → **ON**: 버튼이 **파랑 강조색**, 접근성 값 "켜짐", UserDefaults `autoPlayEnabled` 1.
   - ON으로 켜지면 **즉시** 현재 보드에서 안전한 홈 이동 자동 수행(`runAutoPlay()`).
2. 다시 클릭 → **OFF**(흐림/"꺼짐").
3. **메뉴 게임 > 자동 플레이(`⇧⌘A`)** 도 동일하게 토글 + 켜짐 시 메뉴에 **체크(checkmark)** 표시.
4. 설정 시트(`⌘,`)의 **"자동 이동"** 토글과 즉시 **동기화** — 어느 쪽을 바꿔도 같은 상태값 유지.

## 엣지 케이스

- 승리 기록이 없는 게임(총 0판)을 선택했을 때 상단 카드에 최단 승리 행이 **없음**(나머지 통계만).
- 통계 하단 게임 행을 선택했다가 "전체"로 전환 → 상단은 전체 합계, 행 선택 상태는 유지(복귀 시 그 게임 요약).
- 힌트 중 이동/새 게임/시트 닫힘 시 애니메이션이 즉시 중단되고 오버레이가 남지 않음.
