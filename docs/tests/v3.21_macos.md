## 1. 자동 테스트 — 자동 통과 확인

### FreeCellSolver (11)
- T-210 확장: `solve(gameNumber:variant:budget:) -> SolveResult?` — DFS 이동 수집 + stagnant 가지치기(80) + 무효 이동 2건 수정.
- 풀리는 딜: #1/#2/#50/#100/#500/#1000/#5000/#10000 적용 시 승리 도달. #10은 난이도 높음(2553 이동/134s)으로 목록 제외.
- 미해결: #11982 (MS FreeCell 32000딜 유일 불가능) — 20M/240s에서도 nil.
- 예산 0 → nil. 미지원 변형 → nil.

### Difficulty (6)
- 노드 경계: <20k 쉬움, <150k 보통, 그 외 어려움.
- `measure`: #1 easy, klondike/spider 미지원 unmeasured, 미해결(#11982) unmeasured.

### DailyChallenge 9판 (9)
- 결정성(같은 날짜 같은 9판), 9개 구성·변형 중복 없음·번호 범위, 12종 부분집합, 월/일 변경 시 순서 변화, 단건 API 호환, 별점 경계(승리/시간/이동 1+1+1, 최대 3).

### ChallengeStore 9판 기록 (8)
- `recordDeal`: 추가/누적(다른 판)/별점 업그레이드만(하위 무시). 기존 단건 → 9판 구조 호환 변환. `totalStars`/`completedCount` 집계.

### CalendarMonth/월 통계 (7)
- 월 경계(1→전년 12, 12→다음 해 1), 3개월 목록, 일 수(윤년 2/29), 날짜 포함, `MonthSummary`(완료/총/별/변형 분포), `MonthBadge`(25/50/75/100% 경계).

### FreeCellGame/리플레이 (기존)
- `applyForReplay`는 undo 스택/이동 수 오염 없음, 리플레이 히스토리 동기화.
