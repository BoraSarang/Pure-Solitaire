# 수동 테스트 방법·기대 반응 — v3.11.0 (macos)

> 대상: Pure FreeCell v3.11.0 (11개 변형) — **설정 색상/패턴 미리보기**
> 실행: `./scripts/build_and_run.sh release` → `~/Applications/Pure FreeCell.app`
> 본 가이드는 설정 시트의 3개 선택(카드 스타일/배경/카드 뒷면) 미리보기 검증용.

---

## 1. 카드 스타일 미리보기

1. `⌘,` 또는 메뉴 **게임 > 설정...** → 설정 시트 열림.
2. **카드** 섹션에 **클래식 / 심플** 미니 카드 앞면 2개가 표시됨.
   - 클래식: 흰 바탕 + serif 폰트 + 회색 테두리
   - 심플: 연회색 바탕 + rounded 폰트 + 연두 회색 테두리
3. 현재 스타일 셀에 **파랑 테두리 + 파랑 라벨** 하이라이트.
4. 반대 셀 클릭 → 하이라이트 이동 + 게임 보드 카드가 즉시 해당 스타일로 변경.

## 2. 배경 색상 미리보기

1. **보드** 섹션에 **그린 / 블루 / 다크 / 화이트** 색 스와치 4개가 표시됨 (실제 배경색 그대로).
2. 현재 배경 셀 하이라이트. 셀 클릭 → 하이라이트 이동 + 게임 보드 felt가 **실시간** 해당 색으로 변경.
   - 그린(짙은 초록) / 블루(파랑) / 다크(짙은 회) / 화이트(밝은 회백)
3. **보드 줌** 슬라이더는 기존과 동일.

## 3. 카드 뒷면 패턴 미리보기

1. **보드** 섹션 하단에 **클래식 / 블루 / 골드** 미니 카드 뒷면 3개가 표시됨 (tint/accent 패턴).
2. 셀 클릭 → 하이라이트 이동 + 새 게임(또는 딜 중) 카드 뒷면이 해당 패턴으로 표시.
3. 미리보기 패턴과 실제 게임 보드 뒷면이 **동일**해야 함.

## 엣지 케이스

- 배경 **화이트** 선택 시: 카드 흰 면과 보드 밝은 회백이 구분되는지(가독성) 확인.
- 카드 뒷면 **골드** 선택 후 Klondike/Spider(뒷면이 보이는 게임) 딜 → 골드 패턴 확인.
- 설정 시트가 좁은 창에서도 미리보기 셀이 잘리지 않는지 확인 (폭 460 기준).
