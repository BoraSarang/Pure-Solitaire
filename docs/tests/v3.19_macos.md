# 수동 테스트 방법·기대 반응 — v3.19.0 (macos)

> 대상: Pure Solitaire v3.19.0 (12개 변형) — **점수 체계**
> 실행: `bash scripts/package_release.sh 3.19.0` → `~/Applications/Pure Solitaire.app`
> 본 가이드는 v3.19 점수 체계 검증용.

---

## 1. 이동 점수 누적

1. FreeCell에서 새 게임 시작 → 게임 정보에 **"점수 0"** 표시.
2. 이동(열→열/홈/프리셀)을 할 때마다 점수가 누적되는지 확인.
   - 홈 이동 +10, 열→프리셀 등은 변형별 상수에 따라 증감.
3. Klondike에서 스톡 드로(+5)/웨이스트 재활용(-100)/뒤집기(+5) 등이 반영.

> 기대: 이동마다 점수가 변동, 게임 정보 라벨에 실시간 반영.

## 2. 승리 보너스/최종 점수

1. 게임을 승리 → 승리 배너에 **"최종 점수 N점"** 표시.
2. Klondike 계열은 +500, Spider는 +800, 제거 기반(골프/피라미드/트리피크스)은 +300.
3. Spider에서 열 완성(K→A 13장)마다 +100 추가, Klondike는 10초당 -2 시간 패널티.

> 기대: 최종 점수 = 누적 이동 점수 + 승리 보너스(±패널티).

## 3. undo/redo 롤백

1. 점수를 만든 뒤 `⌘Z` → 점수가 **이동 전 점수로 롤백**.
2. `⇧⌘Z` → 다시 복구.
3. 새 게임(`⌘N`) → 점수 **0** 초기화.

> 기대: undo/redo가 점수 히스토리와 함께 롤백/복구, 새 게임 초기화.

## 4. 통계 기록

1. 승리한 게임 → 통계(`⌘T`) 최근 승리 목록에 **승리 점수**가 표시.
2. 변형별 상세에서도 해당 기록 점수 확인.

> 기대: 승리 기록에 score 필드 저장, 기존 기록(점수 없음)은 호환(표시 생략).

## 5. 변형별 점수 행동

- FreeCell/Baker's/Sea Tower/Super FreeCell: 홈 이동 +10 기반.
- Klondike/Yukon/Forty Thieves: 스톡 드로 +5, 홈 +10, 꺼내기 -15, 재활용 -100, 뒤집기 +5.
- Spider: 완성 수트 +100, 승리 +800.
- Golf/Pyramid/TriPeaks: 제거 +5/카드 값 기반, 승리 +300.
- Scorpion: 그룹 이동/예비 딜, 승리 보너스 확인.

> 기대: 변형 전환 시에도 점수가 해당 변형 상수로 정상 계산, 크래시 없음.
