# 수동 테스트 방법·기대 반응 — v3.10.0 (macos)

> 대상: Pure FreeCell v3.10.0 (11개 변형) — **게임 형식 선택 그리드**
> 실행: `./scripts/build_and_run.sh release` → `~/Applications/Pure FreeCell.app`
> 본 가이드는 게임번호 시트의 게임 형식 선택 UI(픽커 → 미리보기 카드 그리드) 검증용.

---

## 1. 게임 형식 선택 그리드 (신규 — v3.10)

1. `⌘G` 또는 메뉴 **게임 > 게임 번호...** → 시트가 열림. 기존 드롭다운 픽커가 **3열 카드 그리드**로 교체되어 있어야 함.
2. **11개 타일**이 그리드에 표시: FreeCell / Baker's Game / Klondike (1행), Spider / Sea Tower / Super FreeCell (2행), Yukon / Forty Thieves / Golf (3행), Pyramid / TriPeaks (4행).
3. 각 타일 = **0.7 비율 카드** 안에 해당 게임의 **미니 보드 미리보기**가 그려짐:
   - FreeCell 계열: 홈셀 4 + 프리셀(4~6) + 열 8
   - Klondike: 스톡 + 웨이스트 + 홈셀 4 + 열 7 (뒷면 카드 표시)
   - Spider: 스톡 5더미 + 완성 슬롯 + 열 10 (뒷면 카드 표시)
   - Yukon: 홈셀 4 + 열 7, **프리셀 없음**
   - Forty Thieves: 스톡 + 웨이스트 + 홈셀 8 + 열 10
   - Golf: 스톡 + 웨이스트 + 열 7 (전부 앞면)
   - Pyramid: 피라미드 7줄 + 스톡 + 웨이스트
   - TriPeaks: 3개 피크 + 스톡 + 웨이스트
   - 타일 미니 보드의 펠트 색은 **현재 설정 배경색**(그린/다크 등)을 따름
4. **현재 게임 타일**은 파랑 테두리 + 파랑 게임명으로 선택 표시. (시트를 다시 열어도 자동 유지)
5. **다른 타일 클릭** → 파랑 선택이 이동(호버 시 확대). **게임은 바로 시작되지 않음** — 창 제목/보드 그대로.
6. 게임명이 선택 상태에 따라 파랑/회색으로 표시.

## 2. 게임 시작 / 취소

1. 타일 선택 후 게임 번호 입력 → **게임 시작** → 선택한 게임+번호로 게임 시작, 창 제목에 게임명 반영.
2. Spider 타일 선택 시 **난이도(초급/중급/고급)** 세그먼트가 시트에 표시 — 다른 게임에서는 표시되지 않음.
3. **취소** → 게임 변경 없음, 시트만 닫힘. 다시 열면 현재 게임이 선택돼 있음.
