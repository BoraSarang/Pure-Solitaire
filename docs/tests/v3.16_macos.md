# 수동 테스트 방법·기대 반응 — v3.16.0 (macos)

> 대상: Pure Solitaire v3.16.0 (12개 변형) — **데일리 딜**
> 실행: `bash scripts/package_release.sh 3.16.0` → `~/Applications/Pure Solitaire.app`
> 본 가이드는 v3.16 데일리 딜 검증용.

---

## 1. 데일리 딜 진입 (`⌘D`)

1. 사이드바 **"데일리 딜"**(calendar 아이콘) 클릭 또는 메뉴 **게임 → 데일리 딜**(`⌘D`).
2. 현재 변형의 **오늘 날짜 기반 고정 딜**이 시작됨(게임 번호 표시 = 데일리 시드).
3. 같은 날짜+같은 변형이면 **항상 같은 배치** — 새로 시작해도 동일한지 확인.

> 기대: `⌘D`로 즉시 시작, 배치는 날짜·변형에 결정적.

## 2. 변형별 데일리 분리

1. FreeCell에서 `⌘D` → 데일리 딜 시작, 게임 번호 기록.
2. 게임 전환(사이드바)으로 다른 변형(예: Klondike) 전환 후 `⌘D` → **다른 게임 번호**의 데일리 딜 시작.
3. 다시 FreeCell로 돌아가 `⌘D` → 1번과 **같은 번호** 복귀.

> 기대: 변형마다 데일리 시드가 다르고, 같은 변형은 같은 날짜 내에서 재현 가능.

## 3. 확인 다이얼로그

1. 게임 진행(이동 1회 이상) 후 `⌘D` → **"이동 N회가 사라집니다"** 확인 다이얼로그 표시.
2. **확인** → 데일리 딜 시작, **취소** → 기존 게임 그대로 유지.

> 기대: 진행 중 게임 보호, 승리 상태/새 게임 직후엔 다이얼로그 없이 바로 시작.

## 4. 통계/기록 반영

1. 데일리 딜을 승리 → 통계(`⌘T`)에 현재 변형 승리로 기록, 최근 승리 목록에 게임 번호(데일리 시드) 표시.
2. 게임 번호 표시가 데일리 시드 번호와 일치.

> 기대: 데일리 딜도 기존 승리/통계/기록 파이프라인 그대로 사용.
