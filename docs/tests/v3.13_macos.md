# 수동 테스트 방법·기대 반응 — v3.13.0 (macos)

> 대상: Pure Solitaire v3.13.0 (11개 변형) — **승리 자동 완성 / 이동 수 통계 / Klondike 스톡 1·3장**
> 실행: `bash scripts/package_release.sh 3.13.0` → `~/Applications/Pure Solitaire.app`
> 본 가이드는 v3.13 3건 기능 검증용.

---

## 1. 승리 자동 완성 (기본 켬)

1. 홈셀 중심 게임(FreeCell/Klondike/Yukon/Forty Thieves 등)에서 **승리 직전 상태**를 만든다.
   - 예: 어떤 카드든 홈으로 이동이 가능한 상태(모든 잔여 카드가 홈 이동 가능)로 만든 뒤 마지막 1회 이동.
2. 마지막 이동을 성공적으로 적용 → **남은 카드가 홈셀로 자동 정리**되며 소리 + 메시지("자동 완성: N장을 마무리했습니다.") + 승리 연출 표시.
3. 승리 후 `⌘Z`(이동 취소) 여러 번 → 자동 완성 이동이 **undo 스택에 포함**되어 하나씩 복귀 가능.
4. 설정(`⌘,`) → **"승리 자동 완성"** 토글을 끄면 위 동작이 발생하지 않음(마지막 이동 후 그대로 멈춤).

> 기대: 승리 직전에는 항상 자동 정리, 토글 꺼짐 시엔 수동만. spider/golf/pyramid/triPeaks에서는 동작하지 않음(홈 이동 구조 없음).

## 2. 이동 수 통계

1. 게임을 승리 → 통계 시트(`⌘T`) 열기.
2. 상단 요약(선택/전체)에 **"최소 이동 (승리)"**(전체) / **"최소 이동"·"평균 이동"**(선택) 행 표시.
3. 하단 게임별 행 상세 펼침 → **최근 승리 목록의 각 행에 "N 이동"** + 최단 승리 시간 표시.
4. 여러 판을 승리 → 최소 이동이 갱신되고(0 제외), 평균 = 총 이동/승리 수 반올림.
5. 설정 → 통계 초기화 → 최소/평균 이동 행이 사라짐(기록 없음).

> 기대: 승리 시마다 기록, 최소 이동은 0이 아닌 최솟값으로만 갱신.

## 3. Klondike 스톡 드로 1·3장

1. 게임 번호 시트(새 게임) 또는 설정 **"게임별 옵션"** → Klondike의 **"스톡 드로"** → **"3장"** 선택.
2. Klondike 게임 열고 스톡 클릭 → **3장씩 웨이스트로 이동**, 각 웨이스트 **맨 위 1장만** 조작 가능.
3. 스톡이 비면(+웨이스트 비지 않으면) **재활용** → 이전 웨이스트 역순으로 다시 드로, 순서 유지.
4. 다시 "1장" 선택 후 새 게임 → 1장씩 드로(기본 동작).

> 기대: 3장 드로 시 남은 잔량(1~2장)도 그 장수만 드로, 재활용 후에도 순서·드로 장수가 올바름.
