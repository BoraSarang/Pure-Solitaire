# 수동 테스트 방법·기대 반응 — v3.20.0 (macos)

> 대상: Pure Solitaire v3.20.0 (12개 변형) — **승리 보장 (Winnable)**
> 실행: `bash scripts/package_release.sh 3.20.0` → `~/Applications/Pure Solitaire.app`
> 본 가이드는 v3.20 Winnable 옵션 검증용 (FreeCell 계열 4종).

---

## 1. Winnable 옵션 확인

1. 게임 번호 시트(`⌘G`) → FreeCell 계열(**FreeCell / Baker's Game / Sea Tower / Super FreeCell**) 선택.
2. 시트 하단에 **"승리 보장"** 세그먼트("일반"/"승리 보장") 표시.
3. **승리 보장** 선택 시 안내 문구 "풀리지 않는 번호는 다음 풀리는 번호로 시작됩니다" 표시.

> 기대: FreeCell 계열 4종에만 옵션 표시, 다른 변형(예: Klondike)엔 없음.

## 2. 승리 보장 ON 동작

1. "승리 보장" 선택 + 게임 번호 입력(예: #500 — 알려진 난제) → "게임 시작".
2. 시작된 게임 번호가 입력한 번호와 **다를 수 있음**(다음 풀리는 번호로 이동) — 표시·저장된 번호로 확인.
3. 게임을 **실제로 끝까지 풀 수 있는지** 확인(직접 플레이 또는 설정 "승리 자동 완성"을 켜 둔 상태로 승리 직전까지 진행).

> 기대: 풀리는 번호로 자동 시작, 그 게임은 끝까지 승리 가능.

## 3. 일반(OFF) 동작

1. "일반" 선택 + 같은 번호 입력 → **입력한 번호 그대로** 시작(기존 동작 불변).
2. 풀리지 않는 번호여도 즉시 시작(솔버 미동작).

> 기대: OFF면 기존 게임 번호 동작 그대로.

## 4. 시작 지연 확인

1. "승리 보장" ON + 새 게임 시작 → 탐색이 길면 **최대 ~1초**(WinnableSearchBudget) 지연 후 시작.
2. 대부분의 번호는 즉시(수십 ms) 시작.

> 기대: 체감 지연이 길지 않음, 블로킹 크래시 없음.

## 5. 변형별 확인 (4종)

- FreeCell: #1은 풀리는 딜(바로 그대로 시작), #500(난제)은 다음 풀리는 번호로 이동.
- Baker's Game / Sea Tower / Super FreeCell: 각각 승리 보장 ON으로 1~2판 시작·풀이 확인.

> 기대: 4종 모두 승리 보장이 정상 동작, 각각 풀리는 번호로 시작.
