# 수동 테스트 방법·기대 반응 — v3.14.0 (macos)

> 대상: Pure Solitaire v3.14.0 (11개 변형) — **전체 힌트 강조**
> 실행: `bash scripts/package_release.sh 3.14.0` → `~/Applications/Pure Solitaire.app`
> 본 가이드는 v3.14 기능 검증용.

---

## 1. 전체 힌트 강조 (`⇧⌘H`)

1. 아무 게임(FreeCell/Klondike 등)에서 이동 가능한 상황 준비.
2. `⇧⌘H`(또는 사이드바 **"전체 힌트"** 클릭) → **모든 이동 가능한 소스 카드가 동시에 노란 테두리**로 강조.
   - 예: 홈 이동 가능한 열 맨 위 카드 + 열→열 이동 가능한 카드 묶음이 한 번에 모두 표시.
3. 사이드바 "전체 힌트" 버튼이 **강조색(파랑) + 접근성 "켜짐"** 상태가 됨.
4. 다시 `⇧⌘H` → 전체 강조 해제(버튼 원상 복귀, "꺼짐").

> 기대: 단일 힌트(⌘H)의 카드 1곳보다 훨씬 많은 소스가 동시에 강조됨. 버튼 상태가 ON/OFF 반영.

## 2. 단일 힌트와의 병행 동작

1. 전체 힌트 ON 상태에서 `⌘H` → **후보 순환 + 소스→목적지 왕복 2회 애니메이션**은 그대로 동작.
2. `Enter` → 강조된 단일 힌트만 **실제 적용**, 적용 후 전체 힌트는 자동 해제.
3. `⌘H`로 순환 중에도 전체 힌트 강조는 유지(서로 독립).

> 기대: 전체/단일 힌트가 서로 간섭하지 않고, 이동 적용 시에만 전체 강조가 꺼짐.

## 3. 자동 해제 조건

- [ ] 전체 힌트 ON → 아무 **이동 적용** → 강조 사라짐.
- [ ] 전체 힌트 ON → **새 게임**(⌘N) → 강조 사라짐.
- [ ] 전체 힌트 ON → **게임 전환**(사이드바) → 강조 사라짐.
- [ ] 전체 힌트 ON → `⌝ 커맨드`나 gameNumber 시트 열고 닫기 → 유지(해제 아님).

## 4. 게임별 확인 (대표)

- FreeCell: 열→열/열→홈/열→프리셀 소스 동시 강조.
- Klondike: 열→홈/웨이스트→홈 + 열→열(뒤집힘 포함) 소스, 홈셀의 "도착 가능" 표시(홈 소스 아님, 소스 관련은 열 맨 위).
- Pyramid/TriPeaks: 합 13/1 랭크 차이 제거 가능한 **노출 카드** 동시 강조.
- Spider: (전체 힌트 소스는 `columnToColumn` 대상만) 시퀀스 이동 가능 열 강조.

## 5. 영속성/회귀

- [ ] 전체 힌트 토글은 **세션 상태**(앱 재시작 시 꺼짐).
- [ ] `⌘H` 단일 힌트 + `Enter` 적용 + `⌘Z` 실행 취소 각각 정상 (기존 동작 불변).
- [ ] `⌘T`/`⌘,`/`⌘N`/`⇧⌘A` 정상.
