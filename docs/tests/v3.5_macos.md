## 8. Forty Thieves (신규 — v3.5)

1. 사이드바 순환으로 "Forty Thieves" 진입 → **2덱 104장**, **10열×4장**(전부 앞면), **스톡 64장**, 상단 **홈셀 8개**(우측). 상단 좌측에 스톡(뒷면 묶음) + 웨이스트.
2. 스톡 클릭 → 웨이스트에 1장 드로. **스톡 소진 후 스톡 클릭 → 아무 일도 없음 (재활용 없음)**.
3. 웨이스트 카드 클릭 → 선택. 드래그 → 열/홈셀 이동. 더블클릭 → 홈셀.
4. 열 이동: **같은 수트 K→A 내림차순** (위→아래로 내림차순 쌓임). 교대색 아님 — 다른 수트는 거부.
5. **빈 열엔 아무 카드** 배치 가능 (K 제한 없음).
6. 그룹 이동: 열 바닥에서 같은 수트 내림차순 시퀀스만 선택/드래그 가능.
7. 홈셀: 열 맨 위/웨이스트 → 홈 (A→K 같은 수트, 2덱이므로 수트당 2홈). 같은 수트는 어느 홈으로든 이어지지만 A는 빈 홈 우선.
8. 승리 = 홈셀 8개 모두 13장 → 승리 배너 + confetti. 기록/통계는 `fortyThieves` 항목으로 분리 저장.
9. 자동 플레이 켜짐 → 열→홈/웨이스트→홈 가능한 경우 자동 연쇄 수행.
10. 힌트(H) 우선순위: 홈 이동 > 웨이스트→열 > 열→열 > 드로.
11. undo/redo/자동저장 복원 정상.

## 엣지 케이스 (Forty Thieves)

- 게임 번호 617 → 스톡 64장/열 4장 배치 재현 (같은 번호 = 같은 배치).
- 스톡을 모두 드로(64회)한 뒤 웨이스트에서 열/홈 이동만 가능.
- 웨이스트가 비고 스톡도 비면 드로/재활용 모두 없음 → 힌트는 열→열만 제안.
- 승리 전 이동 불가 상태 → "이동 가능한 수가 없습니다." 메시지.
