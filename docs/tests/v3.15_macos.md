# 수동 테스트 방법·기대 반응 — v3.15.0 (macos)

> 대상: Pure Solitaire v3.15.0 (12개 변형) — **커스텀 배경 / 카드 뒷면 2종 / 카드 앞면 2종**
> 실행: `bash scripts/package_release.sh 3.15.0` → `~/Applications/Pure Solitaire.app`
> 본 가이드는 v3.15 3건 기능 검증용.

---

## 1. 커스텀 배경 (사진 업로드/제거)

1. 설정(`⌘,`) → **배경** 픽커에서 맨 끝 **커스텀** 항목 선택.
2. **"이미지 선택…"** 클릭 → NSOpenPanel에서 사진 선택.
3. 보드/창 배경이 선택한 사진으로 즉시 렌더됨.
4. 설정을 닫고 앱 재시작 → **커스텀 배경 유지**(`Application Support/Pure Solitaire/custom-background.png`).
5. 설정 → 커스텀 → **"제거"** → 기본 그린 배경으로 복귀, 재시작 후에도 유지.

> 기대: 커스텀 선택 + 이미지 선택 시 즉시 반영, 제거 시 기본 그린 폴백. 이미지가 누락된 상태에서도 크래시 없이 그린 렌더.

## 2. 카드 뒷면 (오션/숲 추가)

1. 설정 → **카드 뒷면** 픽커에서 **클래식/블루/골드/오션/숲** 5종 확인.
2. 오션 선택 → 딜 중/카드 뒷면이 파란 계열(tint/accent)로 표시.
3. 숲 선택 → 초록 계열로 표시.
4. 각 선택이 설정 미리보기 셀에 실시간 반영되고, 새 게임/딜 애니메이션에도 적용.

> 기대: 5종 전부 렌더, 선택 즉시 보드에 반영(미리보기 자동 반영).

## 3. 카드 앞면 (레트로/딥 추가)

1. 설정 → **카드 스타일** 픽커에서 **클래식/심플/레트로/딥** 4종 확인.
2. **레트로** → 세리프 + 아이보리 배경의 앞면 렌더.
3. **딥** → 다크 배경 + 밝은 면색(심볼/랭크 대비) 앞면 렌더.
4. 각 스타일로 게임을 시작해 보드 카드 앞면이 해당 스타일로 표시되는지 확인(게임 번호 시트 미리보기 포함).

> 기대: 4종 전부 렌더, 선택 즉시 보드 카드 앞면에 반영(픽커 미리보기 자동 반영).
