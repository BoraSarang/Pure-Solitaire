# 수동 테스트 방법·기대 반응 — v3.17.0 (macos)

> 대상: Pure Solitaire v3.17.0 (12개 변형) — **데일리 챌린지 + 업적**
> 실행: `bash scripts/package_release.sh 3.17.0` → `~/Applications/Pure Solitaire.app`
> 본 가이드는 v3.17 데일리 챌린지/업적 검증용.

---

## 1. 데일리 챌린지 진입 (`⌥⌘D`)

1. 사이드바 **"챌린지"** 클릭 또는 메뉴 **게임 → 챌린지**(`⌥⌘D`).
2. 오늘 변형·게임 번호(시드)·별점 3점 목표(승리/시간/이동 수)가 시트에 표시.
3. **"챌린지 시작"** → 해당 변형+시드로 게임 시작.

> 기대: 날짜별 고정(같은 날이면 항상 같은 챌린지), 별점 목표가 변형별 기준에 맞게 표시.

## 2. 별점 기록

1. 오늘 챌린지를 승리 → **별점(승리 +1) 기록**, 시간/이동 목표 충족 시 각각 +1(최대 3점).
2. 챌린지 시트 재진입 → 오늘 완료 표시 + 획득 별점이 표시.
3. 덜 좋은 성적으로 다시 승리 → **더 높은 별점으로 갱신**(낮은 성적은 덮어쓰지 않음).
4. 다른 날짜가 되면(시뮬레이션 불가 시 생략 가능) 새 챌린지로 초기화.

> 기대: 승리·시간·이동 별이 독립적으로 기록, 최대 별점 유지.

## 3. 업적 진입 (`⌥⌘T`)

1. 사이드바 **"업적"** 클릭 또는 메뉴 **게임 → 업적**(`⌥⌘T`).
2. 배지 그리드 — **잠금(회색)/해제(컬러)** 상태 표시.
3. 해제 조건에 맞는 플레이(첫 승리/승리 10회/1분 내 승리/연승 등) → 승리 시 배지 자동 해제.

> 기대: 10개 배지가 조건 충족 시 즉시 해제, 중복 해제 없음(한 번만 기록).

## 4. 업적 종류 (10개)

- [ ] 첫 승리
- [ ] 승리 10회
- [ ] 승리 50회
- [ ] 첫 연승
- [ ] 5연승
- [ ] 변형 1종 완주
- [ ] 변형 5종 완주
- [ ] 게임 100판
- [ ] 1분 이내 승리
- [ ] 챌린지 별 3

## 5. 승리 시 챌린지/업적 동시 반영

1. 오늘 챌린지 게임에서 승리 → 챌린지 별점 기록 + 충족된 업적 배지가 동시에 해제되는지 확인.
2. `⌥⌘T` 업적 시트에서 해당 배지 해제 확인, `⌥⌘D` 챌린지 시트에서 별점 확인.

> 기대: 승리 처리 시 활성 챌린지가 오늘 것이면 별점 자동 기록 + 업적 잠금 해제 갱신.

## 6. 영속성/회귀

- [ ] 챌린지 완료/별점 상태 앱 재시작 유지(UserDefaults).
- [ ] 업적 해제 상태 앱 재시작 유지.
- [ ] `⌥⌘D`/`⌥⌘T` 단축키 동작.
- [ ] 통계(`⌘T`)의 승리 기록이 챌린지 게임과 일반 게임 모두 정상 기록.
