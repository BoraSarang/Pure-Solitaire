## 9. Golf (신규 — v3.6)

1. 사이드바 순환으로 "Golf" 진입 → **7열×5장**(전부 앞면, 35장) + 상단 **스톡(뒷면 묶음) + 웨이스트(앞면 카드 1장)**. 홈셀/프리셀 없음.
2. **열 맨 아래 카드 클릭** → 웨이스트 맨 위 카드와 **1 차이 또는 같은 랭크**(수트 무관)이면 제거되어 웨이스트 위에 쌓임. 아니면 아무 일도 없음.
3. **K↔A 순환**: 웨이스트가 A면 K 제거 가능, 웨이스트가 K면 A 제거 가능.
4. **열 맨 아래 카드 드래그 → 웨이스트에 드롭** → 제거. (맨 아래 카드만 드래그 가능, 그 위 카드는 드래그 소스 아님)
5. 스톡 클릭 → 웨이스트에 1장 드로. **스톡 소진 후 클릭 → 아무 일도 없음 (재활용 없음)**.
6. **승리** = 7열 모두 비어있음 → 승리 배너 + confetti. 기록/통계 `golf` 항목 분리.
7. **종료** = 스톡 소진 + 제거 가능 카드 없음 → "이동 가능한 수가 없습니다." 메시지.
8. 자동 플레이: 켜도 아무것도 하지 않음 (제거 기반 게임).
9. undo/redo/자동저장 복원 정상. 힌트(H)는 제거 가능한 열 → 드로 순으로 제안.

## 10. Pyramid (신규 — v3.7)

1. 사이드바 순환으로 "Pyramid" 진입 → **피라미드 7줄**(28장, 맨 아래 줄 카드가 크게 하이라이트) + 상단 **스톡(뒷면 묶음) + 웨이스트(빈 상태 시작)**. 홈셀/프리셀 없음.
2. **노출 카드 탭** → 두 노출 카드의 합이 **13**이면 (예: 6+7, A+Q, 2+J) 둘 다 제거되고 아래 카드가 새로 노출됨. 합 13이 아니면 선택만 바뀜.
3. **K 탭** → 즉시 단독 제거 (K=13).
4. **노출 카드 탭 + 웨이스트 맨 위 합 13** → 즉시 둘 다 제거.
5. **노출 카드 드래그 → 웨이스트에 드롭** → 웨이스트와 합 13이면 제거.
6. 스톡 클릭 → 웨이스트에 1장 드로. **스톡 소진 후 클릭 → 아무 일도 없음 (재활용 없음)**.
7. **승리** = 피라미드 28장 전부 제거 → 승리 배너 + confetti. 기록/통계 `pyramid` 항목 분리.
8. **종료** = 스톡 소진 + 합 13 짝/K 없음 → "이동 가능한 수가 없습니다." 메시지.
9. 자동 플레이: 켜도 아무것도 하지 않음 (제거 기반 게임).
10. undo/redo/자동저장 복원 정상. 힌트(H)는 K → 짝 → 웨이스트 짝 → 드로 순으로 제안.

## 엣지 케이스 (Pyramid)

- 게임 번호 617 → 피라미드 28장 + 스톡 24장 배치 재현.
- 위 줄 카드는 아래 자식 2장이 모두 제거돼야 노출 — 절반만 제거하면 비노출 유지.
- K는 합 13 짝이 아니라 단독 제거 (K+어떤 카드와도 짝 불가).

- 승리 직전 이동 불가 → 종료 메시지.

## 11. TriPeaks (신규 — v3.8)

1. 사이드바 순환으로 "TriPeaks" 진입 → **3개 피크**(각 4줄, 30장) + 상단 **스톡(뒷면 묶음) + 웨이스트(앞면 카드 1장)**. 홈셀/프리셀 없음.
2. **노출 카드 클릭** → 웨이스트 맨 위 카드와 **정확히 1 랭크 차이**(수트 무관)면 웨이스트로 제거되어 쌓임. 아니면 아무 일도 없음.
3. **같은 랭크·2 랭크 차이·K↔A 순환은 불가** (Golf와 다름): 웨이스트 9면 8/10만 제거, 9/7/A 불가.
4. **노출 카드 드래그 → 웨이스트에 드롭** → 1 랭크 차이면 제거.
5. 스톡 클릭 → 웨이스트에 1장 드로. **스톡 소진 후 클릭 → 아무 일도 없음 (재활용 없음)**.
6. **승리** = 3개 피크 30장 전부 제거 → 승리 배너 + confetti. 기록/통계 `triPeaks` 항목 분리.
7. **종료** = 스톡 소진 + 1 랭크 차이 노출 카드 없음 → "이동 가능한 수가 없습니다." 메시지.
8. 자동 플레이: 켜도 아무것도 하지 않음 (제거 기반 게임).
9. undo/redo/자동저장 복원 정상. 힌트(H)는 피크 제거 → 드로 순으로 제안.

## 엣지 케이스 (TriPeaks)

- 게임 번호 617 → 3피크 30장 + 웨이스트 1장 + 스톡 21장 배치 재현.
- 각 피크의 위 줄 카드는 아래 자식 2장이 모두 제거돼야 노출 (피크 간 독립).
- K와 A는 1 랭크 차이가 아니므로 서로 제거 불가.
- 웨이스트가 빈 상태일 일은 없음 (딜 시 1장 시작) — 방어 로직은 제거 거부.
- 승리 직전 이동 불가 → 종료 메시지.
