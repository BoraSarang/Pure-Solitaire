# 수동 테스트 방법·기대 반응 — v3.3.0 (macos)

> 대상: Pure FreeCell v3.3.0 (7개 변형) — 1차 정밀 분석 + 리팩토링/버그 수정(B1~B8, R1~R2) 반영본
> 실행: `./scripts/build_and_run.sh release` → `~/Applications/Pure FreeCell.app`

---

## 0. 기본 조작 공통

| 조작 | 동작 |
|------|------|
| 카드 클릭 | 카드 선택/해제 토글 (시퀀스의 경우 그룹 선택) |
| 카드 더블클릭 (0.35초 내 2회) | 홈셀로 즉시 이동 시도 |
| 카드 드래그 | 카드(그룹)가 커서를 따라다니며 드롭 지점으로 이동 시도 |
| `Space` | 선택된 카드를 홈셀로 이동 시도 |
| `Enter` | 하이라이트된 힌트 이동을 적용 |
| `H` | 힌트 — 이동 가능한 수를 순환하며 하이라이트 |
| `⌘Z` / `⇧⌘Z` | 실행 취소 / 다시 실행 |
| `⌘N` | 새 게임 (진행 중이면 확인 다이얼로그) |
| `⌘+` / `⌘-` / 슬라이더 | 보드 확대/축소 |
| 사이드바 게임 전환 | 7개 변형 순환 (FreeCell→Baker's→Klondike→Spider→Sea Tower→Super FreeCell→Yukon→FreeCell) |

**기대 반응 공통**
- 이동 시 효과음(`.move`), 홈셀 도착 시 `.home` 사운드 + 카드 펄스
- 무효 이동 시 아무 일도 없거나 화면 흔들림 없음 (카드가 원위치 유지)
- 메시지(예: "자동 플레이: N장을 홈셀로 이동했습니다.")가 3초 후 자동 사라짐
- 마지막 이동 후 1초 뒤 자동 저장 → 앱 재실행 시 동일 배치로 복원
- **드래그**: 카드(그룹)를 잡은 지점이 원래 위치를 유지하며 커서를 정확히 따라옴 — 스택 가운데로 점프하지 않음 (T-099)

## 1. FreeCell (기본)

**테스트 항목 / 기대 반응**
1. 새 게임 → 8열×6장+4장, 홈셀 4개(좌)·프리셀 4개(우) 배치. 상단 중앙에 게임명/게임번호/이동 수/시간 표시.
2. 열 맨 아래 카드 클릭 → 파란 테두리 선택. 다시 클릭 → 해제.
3. 교대색 내림차순 시퀀스(맨 아래 N장)를 드래그 → 목적지 열에 유효하면 이동, 무효면 원위치.
4. 빈 열엔 K만 배치 가능 (다른 카드 드롭 시 거부).
5. 더블클릭 → 홈셀로 이동 (A→K 같은 수트 오름차순).
6. 프리셀에 카드 1장 보관/회수. 프리셀에서 홈셀 더블클릭 가능.
7. 힌트(H) → 첫 힌트는 **최우선순위(홈셀 이동)** 부터 표시. 반복 시 다음 후보 순환.
8. 승리(홈셀 4개 완성) → 승리 배너 + confetti + "다음 게임" 버튼. 이동/시간 정지, 기록 저장.
9. 승리 직후 `⌘Z` → 승리 UI 해제·타이머 재개·카드 원위치 (B5 수정 검증).
10. 자동 플레이 켜짐 상태에서 이동 → 가능한 홈 이동을 자동 연쇄 수행.

## 2. Baker's Game

- FreeCell과 동일하나 **같은 수트 내림차순**만 이동 가능 (교대색 아님).
- 빈 열엔 K만.
- **수퍼무브 용량 = 빈 프리셀+1** (빈 열은 용량 계산에서 제외).
- 위 항목 2~10과 동일하게 검증하되 색 조건만 다름을 확인.

## 3. Klondike

1. 스톡 클릭 → 웨이스트에 카드 1장 드로. **스톡 소진 후 스톡 클릭 → 웨이스트가 역순으로 스톡에 재활용** (아이콘 `arrow.uturn.left.circle`).
2. 웨이스트 카드 클릭 → 선택. 드래그 → 열/홈셀 이동. 더블클릭 → 홈셀.
3. **웨이스트 탭이 항상 0열로 가는 버그 없음** (B2) — 선택된 카드를 임의 열에 드롭 가능.
4. 열 맨 아래 앞면 카드만 이동. 뒷면 카드 클릭 → 앞면 뒤집기(노출 시 자동).
5. 교대색 내림차순 시퀀스 이동, 빈 열엔 K만.
6. 홈셀 A→K 오름차순.
7. **뒷면 카드 a11y 라벨이 값을 노출하지 않음** (B3) — VoiceOver로 뒷면 = "뒷면 카드".
8. 승리/undo/자동 플레이 동작 FreeCell과 동일.

## 4. Spider

1. 난이도 선택(1/2/4수트) → 게임 번호 시트에서 세그먼트로 선택, "게임 시작" 누를 때만 반영 (B4).
2. 10열 (열0~3=6장, 열4~9=5장). 앞면 카드만 이동.
3. **같은 수트 K→A 내림차순 시퀀스**만 이동. 빈 열엔 아무 카드.
4. 13장 완성 시 자동 제거 → 우측 "완성 N/8" 카운트 증가 + 사운드.
5. 스톡(상단 5더미) 클릭 → 각 열에 앞면 1장 딜.
6. 승리 = 완성 수트 8개. 홈셀/프리셀/웨이스트 없음.
7. 자동 플레이 없음 (이동 후 자동 연쇄 안 함).

## 5. Sea Tower

1. 10열×5장 교대 딜 + 시작 카드 2장이 프리셀 0,1에 배치.
2. **같은 수트**만 내림차순 이동, 빈 열엔 K만.
3. 수퍼무브 = **빈 프리셀+1** (빈 열 임시 저장 불가).
4. 프리셀/홈셀/드래그 동작 FreeCell과 동일.

## 6. Super FreeCell

1. **2덱 104장**, 10열(4열×11장+6열×10장), 프리셀 6개, 홈셀 4개.
2. **교대색** 내림차순 이동. 빈 열엔 **아무 카드**.
3. 홈셀은 수트 고정 + A→K→A→K 순환(각 26장). 승리 = 4홈 모두 26장.
4. 수퍼무브 = (빈 프리셀+1) × 2^(빈 열) (목적지 빈 열 제외).

## 7. Yukon (신규)

1. 7열 배치: 열0=1장 앞면, 열1~6=뒤집힌 5장+앞면 1~6장. 스톡/웨이스트/프리셀 없음.
2. **앞면 카드 클릭 → 그 위 전부 그룹 선택** (내부 순서 무관, 시작 카드만 목적지 규칙 충족).
3. 교대색 내림차순 이동, 빈 열엔 K만.
4. 뒷면 카드 클릭 불가(이동 소스 아님). 이동으로 노출된 뒷면 카드는 자동 앞면.
5. 홈셀 4개(우측): 열 맨 아래 앞면 카드만 이동(A→K 같은 수트).
6. **홈 힌트 하이라이트가 해당 수트 홈만 강조** (B6) — K 하트 힌트면 하트 홈만 테두리.
7. 힌트 → 열→홈 이동만 제안 우선. 승리 = 홈 4개 모두 13장.
8. **자동 플레이가 홈 이동을 수행** (B1) — 오토플레이 켜짐 상태에서 열→홈 가능한 경우 자동 이동.

## 9. 설정 / 통계 회귀

- 설정: 카드 스타일 2종, 카드 뒷면 2종, 배경 3종, 사운드/BGM 볼륨, 애니메이션 속도, 보드 확대, 자동 플레이 토글.
- 통계: 변형별 총 게임/승리/승률/연승/최고연승/최단시간. 초기화 버튼 → 모든 통계+기록 삭제.
- 창 크기/위치 기억: 크기 조정 후 재실행 시 동일 프레임.
- BGM/효과음 볼륨 슬라이더 반영 즉시.

## 10. 엣지 케이스

- 게임 번호 1, 617, 11982, 1,000,000 입력 → Microsoft와 동일 배치 (FreeCell/Baker's).
- 잘못된 번호("abc", 0, 1000001) → "유효한 번호를 입력하세요 (1 ~ 1,000,000)." 메시지.
- 새 게임 중 진행 확인 다이얼로그에서 "취소" → 현재 게임 유지.
- 이동 불가 상태 → "이동 가능한 수가 없습니다." 메시지.
