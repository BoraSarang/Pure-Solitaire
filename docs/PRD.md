# Pure FreeCell — 제품 요구사항 정의서 (PRD)

## 1. 제품 개요

| 항목 | 내용 |
|------|------|
| 제품명 | Pure FreeCell |
| 태그라인 | 맥을 위해 재탄생한 군더더기 없는 클래식 프리셀. 마이크로소프트 정통 규칙 그대로, 깔끔하게 즐기세요. |
| 플랫폼 | macOS (arm64) 전용 |
| 배포 형태 | `Pure FreeCell.app` → `~/Applications` 설치 |
| 로그인 | 불필요 (로컬 단독 플레이) |
| 기술 스택 | Swift 6 + SwiftUI (네이티브), SwiftPM CLI 빌드 |
| 버전 | v1.0 (프리셀 MVP) |

## 2. 배경

- 마이크로소프트 스토어의 카드 게임 모음(5가지 게임 형식)이 macOS에서 제공되지 않아,
  마이크로소프트 **정통 규칙**을 그대로 따르는 네이티브 앱으로 재탄생.
- 5가지 형식 중 **프리셀(FreeCell)을 먼저 구현**하고, 안정화 후 나머지 게임을 하나씩 추가한다.
- 브랜드 컨셉: "군더더기 없는" — 광고, 로그인, 과도한 그래픽 없이 클래식 프리셀의 본질에 집중.

## 3. 목표 / 비목표

### 목표
- 마이크로소프트 프리셀 규칙을 100% 재현 (딜, 이동, 수퍼무브, 승리 판정)
- 게임 번호(1 ~ 1,000,000) 기반 딜 재현 — MS와 동일한 배치
- 무제한 실행 취소 / 다시 실행
- 직관적인 드래그 & 드롭 + 클릭/더블클릭 조작
- 로컬 통계 및 설정 저장
- 추후 다른 카드 게임을 추가할 수 있는 확장 가능한 아키텍처

### 비목표 (v1.0)
- 로그인, 클라우드 동기화, 멀티플레이
- 온라인 랭킹, 업적
- iOS / iPadOS 지원
- AI 해설 / 자동 풀이 (솔버)

## 4. 게임 규칙 (마이크로소프트 정통)

### 4.1 기본 구성
- 표준 52장 덱 1벌 (조커 없음)
- **타블로(Tableau) 8열**: 4열은 7장, 4열은 6장씩 앞면으로 배치 (총 52장)
- **프리셀(FreeCell) 4칸**: 각 칸에 카드 1장을 임시 보관
- **홈셀(Foundation) 4칸**: 각 무늬별로 A → K 오름차순 완성

### 4.2 배치(딜)
- 게임 번호 `N`을 시드로 한 마이크로소프트 LCG로 셔플
  - `state = (state × 214013 + 2531011) mod 2³¹`
  - `rand = state >> 16` (0 ~ 32767)
  - 초기 state = 게임 번호 & 0x7FFFFFFF
- 카드를 [51..0] 순서로 준비하고 i=0..51에 대해 `j = 51 - (rand % (52-i))`, swap
- 딜 순서: 위에서 아래로, 왼쪽에서 오른쪽으로 8열에 교대로 배치
- 게임 #1, #617 결과가 마이크로소프트와 정확히 일치해야 함 (검증 필수)

### 4.3 이동 규칙
| 이동 | 규칙 |
|------|------|
| 타블로 → 타블로 | 내림차순 + 교대 색(빨강/검정)으로만 쌓기 |
| 타블로 → 프리셀 | 아무 카드나 1장 (빈 칸에) |
| 타블로 → 홈셀 | 같은 무늬 + 현재 맨 위보다 1단계 높은 카드 (A부터 시작) |
| 프리셀 → 타블로 | 내림차순 + 교대 색 규칙 |
| 프리셀 → 홈셀 | 같은 무늬 + 1단계 높은 카드 |
| 빈 타블로 → | 아무 카드(또는 수퍼무브 시퀀스) 배치 가능 |
| 홈셀 → | 홈셀에서 다시 꺼내기 가능 (MS 규칙 허용) |

### 4.4 수퍼무브 (다중 카드 이동)
- 한 번에 이동 가능한 카드 수: `(빈 프리셀 수 + 1) × 2^(빈 타블로 열 수)`
  - 목적지가 빈 열이면 그 열은 임시 저장으로 사용 불가 → 제외
- 이동할 카드 시퀀스는 내림차순 + 교대 색 조건을 만족해야 함

### 4.5 승리 / 패배
- 승리: 모든 카드가 4개 홈셀에 A→K로 완성
- 패배: 이동 가능한 수가 완전히 없을 때 (MS는 "이동 불가" 메시지 표시)

### 4.6 MS 특이사항 재현
- 무제한 실행 취소
- 게임 번호 선택 UI (현재 게임 번호 표시, 변경 시 적용)
- 새 게임: 무작위 게임 번호 (1 ~ 1,000,000)
- 자동 플레이(오토플레이): 안전한 카드만 홈셀로 자동 이동 (토글 가능)

## 5. 기능 명세

### 5.1 게임 보드
- 상단: 4 홈셀(왼쪽) + 4 프리셀(오른쪽), 중간 게임 번호/정보 표시
- 하단: 8개 타블로 열
- 카드는 커스텀 벡터 렌더링 (스타일 선택 가능)

### 5.2 상호작용
- 드래그 & 드롭으로 카드(시퀀스 포함) 이동
- 클릭으로 선택 후 클릭으로 목적지 지정 (연속 이동)
- 더블클릭: 홈셀로 자동 이동 시도
- 홈셀/프리셀/빈 열의 유효한 대상은 하이라이트

### 5.3 메뉴 / 단축키
| 동작 | 단축키 |
|------|--------|
| 새 게임 | ⌘N |
| 실행 취소 | ⌘Z |
| 다시 실행 | ⇧⌘Z |
| 게임 번호 선택 | ⌘G |
| 힌트 | ⌘H |
| 자동 플레이 | ⇧⌘A |
| 통계 | ⌘T |
| 설정 | ⌘, |

### 5.4 힌트
- 유효한 이동 1개를 제안 (홈셀 이동 우선, 그다음 프리셀 → 타블로 등)

### 5.5 통계 (로컬 저장)
- 총 게임 수, 승리 수, 승률
- 현재 연승, 최고 연승
- 최근 게임 번호 (재시작 시 복원)

### 5.6 설정
- 카드 스타일 (클래식 / 심플)
- 배경 색상 (기본 / 다크)
- 자동 플레이(오토플레이) 활성화 여부
- 애니메이션 속도
