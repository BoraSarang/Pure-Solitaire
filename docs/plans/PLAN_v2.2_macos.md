# PLAN v2.2 — 애니메이션/시간/새 게임 확인/사이드바/회귀 테스트 — macOS

> 작성일: 2026-08-05 | platform: macos | 상태: 진행중

## 1. 개요

v2.1 완료 후 다음 5개 작업.

1. **T-031 딜/승리 애니메이션** — 게임 시작 시 카드 딜링 연출, 승리 시 홈으로 날아가는 연출
2. **T-032 게임 시간 측정** — 게임 시작→종료 시간, 최단 승리 시간, 통계 표시
3. **T-033 새 게임 확인 + 승리 후 다음 게임** — 진행 중 새 게임 확인 다이얼로그, 승리 시 "다음 게임" 버튼
4. **T-034 사이드바 보강** — 게임 형식 전환(FreeCell ↔ Baker's Game) 아이콘 버튼 추가
5. **T-035 에지 케이스 회귀 테스트** — 드래그/더블클릭/오토플레이 경계 케이스 테스트 보강

## 2. 결정 사항

- **D2.2-1 딜 애니메이션**: 새 게임 시 카드가 보드 중앙에서 각 열로 떨어지는 간단한 딜링 연출(0.8s). SwiftUI `.transition` + `withAnimation`.
- **D2.2-2 승리 연출**: 모든 카드가 홈에 도착하면 홈셀 카드에 잠시 하이라이트 + 승리 메시지 배너. (카드 비행 애니메이션은 기하학 계산 복잡도 대비 효과 낮아 보류 — 메시지 배너 + 사운드 유지)
- **D2.2-3 시간**: ViewModel에 `gameStartedAt: Date?` 저장(게임 생성 시). 승리 시 소요 시간 계산 → StatsStore `bestTimeSeconds`(변형별) 갱신. StatsView에 표시.
- **D2.2-4 새 게임 확인**: `moveCount > 0` 상태에서 새 게임/새 게임 번호/형식 전환 시 `confirmationDialog`로 확인. 승리 시 메시지에 "다음 게임" 버튼.
- **D2.2-5 사이드바**: 좌측 상단 게임 그룹에 "게임 형식 전환" 아이콘(arrow.left.arrow.right) 버튼 추가 → 현재 변형 반대쪽으로 새 게임.
- **D2.2-6 회귀 테스트**: 드래그 히트 판정 경계, 더블클릭 시퀀스, 빈 열/빈 프리셀 경계, 오토플레이 후 상태 일관성 테스트 추가.
