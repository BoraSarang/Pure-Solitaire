# PLAN — v1.2 [macos] — 접근성 개선 (T-018)

## 개요
- VoiceOver 호환 고도화: 카드/버튼/보드 영역의 접근성 라벨·힌트·값·그룹을 정리해 시각장애 사용자가 게임 상태를 파악하고 조작할 수 있게 한다.
- 키보드 내비게이션(카드 포커스 이동)은 범위가 크므로 **후속 반복**으로 분리 (본 계획은 VoiceOver 정리 우선).

## 결정 사항
1. **카드 접근성**
   - 라벨 유지: "10 ♥" / 빈 자리는 "빈 자리"
   - 힌트 추가: "누르면 선택, 두 번 누르면 홈셀로 이동" (타블로/프리셀 카드)
   - 값 추가: 선택된 카드는 accessibilityValue "선택됨", 미선택은 "선택 안 됨"
   - 홈셀 카드 힌트: "누르면 선택, 홈에서 꺼낼 수 있음"
2. **보드 영역 접근성 그룹**
   - 홈셀(4), 프리셀(4), 각 타블로 열(8)을 컨테이너로 묶어 접근성 라벨 부여
   - 열 라벨: "홈셀 1", "프리셀 2", "열 3" 등 → VoiceOver 내비게이션 순서/문맥 개선
   - 홈셀에 있는 카드 수 표시 (예: "홈셀 1, 5장")
3. **게임 정보 결합**: "게임 번호 967231, 이동 12" 한 요소로 묶어 중복 읽기 방지
4. **사이드바 버튼**: accessibilityLabel(제목) + accessibilityHint(단축키) 명시
5. **메시지 배너**: macOS SwiftUI에는 `accessibilityLiveRegion`가 없어 **제외** (VoiceOver 자동 안내 불가 — 대신 메시지는 이미 화면에 텍스트로 표시)
6. **드래그 오버레이**: `.accessibilityHidden(true)` → 드래그 중 오버레이가 VoiceOver에 노출되지 않게
