✨ 주요 기능

  • 게임 번호 기반 딜 — 1~1,000,000 사이 번호로 MS와 동일 배치 재현 (게임 #1/#617 검증)
  • 직관적인 조작 — 드래그 & 드롭, 클릭 이동, 더블클릭 홈 자동 이동
  • 무제한 실행 취소/다시 실행 — 상태 스냅샷 기반으로 크래시에 안전
  • 자동 플레이 & 힌트 — 안전한 카드 자동 이동 + 드래그 경로 애니메이션
  • 승리 연출 — 파티클(컨페티) + 사운드 시퀀스 + 배너
  • 통계 & 기록 — 게임별 통계·최단 승리·최근 승리 기록 자동 저장
  • 커스터마이징 — 카드 스타일 · 뒷면 패턴 · 배경색 · 보드 줌 · BGM 볼륨
