홈 화면

앱을 열면 바로 카테고리 4그룹 그리드. 하던 게임은 "이어하기" 카드로 한 번에 복귀.

⌘1

자동 풀어 보기

내장 솔버가 승리 경로를 찾아 끝까지 재생. 진행률·속도 3단계·일시정지·중단.

⇧⌘P

내 이동 리플레이

승리한 판을 처음부터 내가 둔 그대로 다시 감상.

⇧⌘R

데일리 도전

매일 9판이 새로 셔플됩니다. 3개월 달력으로 날짜별 완료·별점을 한눈에, 월 배지(브론즈→다이아)로 꾸준함에 보상.

⌥⌘D

게임 번호 딜 · 승리 보장

1~1,000,000 번호로 MS와 동일 배치 재현. FreeCell 계열은 내장 솔버가 풀리는 번호만 자동 선택해 언제나 풀이 가능한 판부터 시작.

⌘G

무제한 실행 취소

상태 스냅샷 기반 — 크래시에 안전한 무한 undo/redo.

⌘Z

통계 & 업적

게임별 통계·최단 승리·최근 기록 + 업적 10개.

⌘T

커스터마이징

카드 스타일 4종 · 뒷면 5종 · 배경색·사진 · 보드 줌 · BGM.

Daily Challenge

오늘의 9판, 내일이면 사라집니다

날짜 시드로 고정된 9가지 게임이 매일 새로 셔플됩니다. 풀어서 별점을 모으고, 월 배지로 꾸준함을 증명하세요.

  • 매일 9판 — 하루하루 다른 구성
  • 별점 3점 — 승리 · 시간 · 이동 수
  • 3개월 달력 — 완료·별점을 한눈에
  • 월 배지 — 브론즈 / 실버 / 골드 / 다이아
  • 판별 난이도 태그 — 내 실력에 맞게
